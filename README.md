# VIA Smart

**Driver Marketplace Network**

Projeto acadêmico desenvolvido para demonstrar uma plataforma de combinação entre demandas de transporte e motoristas, considerando capacidade, habilitação, rota, reputação, disponibilidade e confiança.

## Funcionalidades

- Busca de combinações entre carga e motoristas
- Filtros por tipo e peso da carga
- Avaliação de compatibilidade
- Indicadores de confiança e disponibilidade
- Cadastro de motoristas
- Estimativa de emissão de CO₂
- Simulação de rastreamento da entrega
- Uso opcional da localização do navegador
